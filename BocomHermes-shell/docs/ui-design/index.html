设计总览 桌面客户端 ×5 悬浮卡片 ×8 交互与动效
BocomHermes 客户端设计套件 · v1.0

安静、克制，
为长时间共处的桌面智能体而设计。

BocomHermes 是活在桌面上的个人智能体：透明玻璃对话卡、悬浮球、卡坞、内嵌浏览器与邮件中心。 它一天被注视数小时，所以这套设计的最高原则是 Quiet Utility——没有装饰性渐变、没有多余的描边与投影， 每一个元素都要挣得自己的位置。色彩、字阶、圆角、动效全部来自语义化设计令牌， 深浅双主题只换令牌值，不动一行业务样式。密度与质感对标 Claude Code 桌面端: 信息密而不挤,层级靠字重与不透明度说话,而不是靠盒子和线条。形态上,以一体化桌面主窗口为主(desktop.html), 悬浮球与迷你卡只保留为快捷入口。

01设计原则 → 落地规则

原则不是口号，每一条都翻译成可检查的规则，贯穿后面所有界面与交互稿。

QUIET UTILITY
安静实用
禁装饰性渐变、禁左色条卡片、禁无信息投影。玻璃质感只来自 primary-90 + blur(30px) 这一对令牌。
TOKEN FIRST
令牌先行
任何颜色/字号/圆角先查令牌表。新增样式写语义变量路径(如 labels.secondary),不写死色值。
SEMANTIC HIERARCHY
语义层级
一屏最多一个主按钮。文字层级 = labels.primary→quaternary 四档不透明度,而不是四档字号。
COMPONENT CONTRACT
组件即契约
按钮只有 44/32/26 三档高,开关滑块永远是正圆,Dialog 恒宽 360px。遇到契约没有的形态,先扩充契约再画。
PURPOSEFUL MOTION
动效有因
动效只为解释状态:进场 scale(0.96)+opacity,按压 0.97,抽屉用 ez-drawer。禁 ease-in、禁弹跳、禁无目的漂浮。
