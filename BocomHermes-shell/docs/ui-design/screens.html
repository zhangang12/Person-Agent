悬浮卡片形态

快捷入口形态:迷你卡(盯梢单个会话)与悬浮球。主形态是一体化桌面主窗口,见 desktop.html。 八张界面场景统一取自真实使用:信贷系统开发者在晚上联调月度结息。 每张图下方附令牌注解,标注关键用色/字号/圆角的来源路径,实现时按图索骥。

S1悬浮球 Orb + 全局输入框

桌面常驻入口。悬浮球 56px,玻璃材质与卡片同源;Ctrl+Shift+Space 唤起输入框,就近落在球旁边,视线不用旅行。

S2对话卡 · 基础态

一卡 = 一个独立会话。标题栏从左到右:拖动柄 → 会话色点 → 项目名 → 模型 → 上下文用量 → 保活 → 最小化/关闭。信息密度对标 IDE 标签页。
