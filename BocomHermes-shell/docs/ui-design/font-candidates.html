会话字体候选对比

同一对话卡渲染 · 全部系统自带零打包(内网可用)
怎么选(建议): ① A Microsoft YaHei UI — 雅黑 UI 版,字距/数字最现代,混排最稳(当前在用,默认推荐); ② B Segoe UI Variable — Win11 原生可变字体,拉丁/数字最漂亮,中文回落雅黑 UI(中英文混排多的选它); ③ C 经典雅黑 — 字形饱满、最耐看,但数字偏老派; ④ D 等线 — 笔画细、最清秀,大屏高分屏好看,低分屏慎选(细笔画发虚); ⑤ E 新宋体 — 衬线书卷气,长文档阅读感好,但界面感弱(喜欢"读文档感"的选)。 等宽代码统一 Cascadia Code(各卡一致,不随方案变)。
